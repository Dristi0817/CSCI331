\doxysubsection{Detailed Description}
In-\/\+RAM representation of the simple primary key index. 

The index maps each active block\textquotesingle{}s highest key to its RBN. It uses a std::\+map so the entries are always sorted by key.

Usage pattern:\+ 1) Build the index during file creation (insert entries for each block). 2) Write to disk. 3) At search time, load from disk into RAM. 4) To find a ZIP code, call \doxylink{class_simple_index_a3600b28f336f54b6367f1489043edf2c}{find\+RBN()}; it returns the RBN of the block whose highest key \texorpdfstring{$>$}{>}= the target key (the block that could contain it).

Find the RBN of the block that could contain target\+Key. 

Looks up the first block whose highest key \texorpdfstring{$>$}{>}= target\+Key. If no such block exists, returns -\/1 (the key is beyond the last block).


\begin{DoxyParams}{Parameters}
{\em target\+Key} & ZIP code string to search for (e.\+g. "{}56301"{}). \\
\hline
\end{DoxyParams}
\begin{DoxyReturn}{Returns}
RBN of the candidate block, or -\/1 if not found.
\end{DoxyReturn}
Uses lower\+\_\+bound to find the first entry whose key \texorpdfstring{$>$}{>}= target\+Key. That block is the only one that could contain the record.

Example:\+ Index:\+ 01005→1, 10199→2, 56310→3 Search for "{}05678"{}:\+ lower\+\_\+bound("{}05678"{}) → key "{}10199"{} → RBN 2 Block 2\textquotesingle{}s range is (01005, 10199]\+, so 05678 could be in block 2.
