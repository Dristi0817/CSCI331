\doxysubsection{Detailed Description}
Reads and writes fixed-\/size blocks in a blocked sequence set file. 

Responsibilities:\+
\begin{DoxyItemize}
\item Pack a set of CSV record strings + metadata into a fixed-\/size block buffer.
\item Unpack records from a block buffer back into strings.
\item Read/\+write a block from/\+to disk by Relative Block Number (RBN).
\item Manage per-\/block metadata:\+ predecessor RBN, successor RBN, record count.
\end{DoxyItemize}

This class does NOT know about ZIP codes specifically — it works with arbitrary CSV strings. The caller (\doxylink{struct_zip_code_record}{Zip\+Code\+Record} /\+ main) converts strings to typed objects.
