\doxysubsection{Detailed Description}
High-\/level manager for the blocked sequence set file. 

\doxylink{class_sequence_set}{Sequence\+Set} coordinates:\+
\begin{DoxyItemize}
\item Creating a blocked sequence set from a sorted CSV file.
\item Sequential reading (for Project 1 style analysis).
\item Physical and logical dump methods.
\item Index-\/based record search.
\item Record insertion (with block splitting).
\item Record deletion (with redistribution /\+ merging).
\item Avail-\/list management.
\end{DoxyItemize}

It uses:\+
\begin{DoxyItemize}
\item \doxylink{class_block_buffer}{Block\+Buffer} to pack/\+unpack individual blocks.
\item \doxylink{class_block_header_buffer}{Block\+Header\+Buffer} to read/\+write the file header (RBN 0).
\item \doxylink{class_simple_index}{Simple\+Index} to maintain the in-\/\+RAM \{highest\+Key, RBN\} index.
\item \doxylink{struct_zip_code_record}{Zip\+Code\+Record} as the typed record object.
\end{DoxyItemize}
