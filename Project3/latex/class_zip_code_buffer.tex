\doxysubsection{Detailed Description}
Reads ZIP code records one at a time from a CSV file. 

In Project 3 this is also used as the "{}record buffer"{}:\+ given a raw CSV string (extracted from a block by \doxylink{class_block_buffer}{Block\+Buffer}), call from\+CSV() on a \doxylink{struct_zip_code_record}{Zip\+Code\+Record} to unpack its fields.
