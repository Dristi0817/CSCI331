bool SequenceSet::create ( const string & csvFile,
const string & dataFile,
const string & indexFile )

Create a brand-new blocked sequence set from a sorted CSV file.

Steps: 1) Read the CSV one record at a time (streaming). 2) Pack records into blocks until each block hits 100% capacity. 3) Write each completed block to disk. 4) Build the SimpleIndex entry for each block. 5) Write the index file. 6) Write the file header (RBN 0).

The CSV must already be sorted ascending by ZIP code.

Parameters
csvFilePath to sorted CSV file.
dataFilePath of the blocked sequence set to create.
indexFilePath of the simple index file to create.
Returns
true on success.

The CSV must already be sorted ascending by ZIP code (first field). Each block is filled to capacity before a new block is started.

Parameters
csvFileSorted CSV input.
dataFileOutput blocked sequence set file.
indexFileOutput simple index file.
Returns
true on success.

bool SequenceSet::insert ( const ZipCodeRecord & rec)

Insert a new ZIP code record into the sequence set.

Insert a new record into the sequence set.

Algorithm: 1) Use the index to find the target block. 2) If the record fits, insert in sorted position. 3) If the block is full, split it: a) Obtain an avail block (from avail list or append new block). b) Distribute records evenly between the two blocks. c) Update predecessor/successor links. d) Update the index. Logs block splits to cout.

Parameters

Returns
true on success, false if the record already exists.

◆ remove()

bool SequenceSet::remove ( const string & zipKey)

Delete a ZIP code record from the sequence set.

Delete a record by ZIP key.

Algorithm: 1) Use the index to find the target block. 2) Remove the record from the block. 3) If the block is below the minimum fill: a) Try redistribution with the left or right neighbour. b) If redistribution is not possible, merge with a neighbour. The merged block is added to the avail list. Logs merges / redistributions to cout.

Parameters
zipKeyZIP code string to delete.
Returns
true if found and deleted, false if not found.

After deletion, if the block falls below minimum fill, attempts redistribution with a neighbour; if that is not possible, merges with a neighbour.

Parameters
zipKeyZIP code string to delete.
Returns
true if found and deleted.
