Detailed Description

Simple primary key index for the blocked sequence set.

This index stores ordered pairs {highest key in block, RBN} as described in Folk Figure 10.3. The index is small enough to load entirely into RAM.

On disk the index file has this format: Line 0: SIDX,1 (file type tag + version) Line N: <key> <rbn> (one entry per active block)

Example: SIDX,1 01005 1 02139 2 56301 3
